# 1.0.5-beta compatibility trial

- sing-box subscriptions (`.json` and `-sing-box.json`) no longer include the unsupported `_meta` field.
- Subscriptions are grouped into collapsible Mihomo YAML, LIST, sing-box JSON, and TXT sections. Titles and descriptions support Simplified Chinese, Traditional Chinese, and English.
- Enable **Loon compatibility** in the LIST section, then copy the new `-loon.list` URL. It exports destination ports as `DEST-PORT`. Existing `.list` URLs retain their original format. Quantumult X has its own `-qx.list` entry.
- The bulk import preview scrolls within the available mobile viewport while keeping confirmation actions visible.

## Try the Docker image

Use `cyclince/private-rules:1.0.5-beta` in your Compose file, then run:

```sh
docker compose pull
docker compose up -d
```

Refresh sing-box subscriptions after upgrading. For Loon, replace the previous subscription URL with the compatibility URL. The beta release does not update `latest`.

## Validation

- TypeScript typecheck, 122 unit/integration/contract tests, and 10 Playwright tests.
- Browser coverage includes all three languages and bulk import of 100 rules at 390×667, 667×375, and 320×480.
- Official sing-box 1.12.0 compiles the generated rule-set; adding the former `_meta` field reproduces the reported unknown-field error.
