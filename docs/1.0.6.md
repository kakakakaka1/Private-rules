# 1.0.6 compatibility release

- Fixed strict sing-box source rule-set parsing by removing unsupported top-level metadata.
- Added a dedicated Loon LIST subscription that exports destination ports as `DEST-PORT`.
- Grouped subscriptions into animated, collapsed-by-default Mihomo YAML, iOS LIST, sing-box JSON, and TXT sections.
- Added standalone General, Loon, and Quantumult X links to the iOS LIST section.
- Completed Simplified Chinese, Traditional Chinese, and English labels for subscription formats.
- Fixed the mobile bulk-import preview so its actions stay reachable while the rule list scrolls.
- Replaced transparent Apple touch icon corners with an opaque pale background and versioned the icon URL to avoid stale iOS caches.

Docker images `cyclince/private-rules:1.0.6` and `cyclince/private-rules:latest` support `linux/amd64` and `linux/arm64`.
